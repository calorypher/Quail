# M10 — Desktop shell

## Goal

Deliver the first production WinUI 3 desktop shell for Quail: a resident, single-instance Quick Search surface around controlled results. It remains separate from `Quail.Core`; real index integration is a later milestone.

## Scope

- `src/Quail.App`, an unpackaged Windows 11 x64 WinUI 3 application named `Quail.exe`;
- resident startup, single-instance activation, global configurable hotkey, focus-safe show/hide lifecycle, keyboard result navigation, and controlled result data;
- approved Quail Flow branding assets for the window and tray icons, without regeneration or redrawing;
- tray Show / Settings / Exit affordances and persisted `%LOCALAPPDATA%\Quail\settings.json` settings for hotkey and System/Light/Dark theme;
- PMv2-aware window positioning and M08-derived `visible-ready` lifecycle semantics;
- fully self-contained publish with an explicit guard for unpackaged WinUI XBF, PRI, and SVG payloads.

## Out of scope

- real search/index integration, provider work, ranking, content indexing, service changes, installer/update work, and changes to `Quail.Core`;
- Full Search, browser/web actions, plugin systems, and new branding assets.

## Publish procedure

Run a Release build first, then use the canonical M10 publish script:

```powershell
dotnet build src\Quail.App\Quail.App.csproj -c Release -p:Platform=x64 --no-restore
.\scripts\publish-m10.ps1
```

The script deliberately copies and verifies `App.xbf`, `QuickSearchWindow.xbf`, `Quail.pri`, and `Assets\quail-feather-A-gradient.svg`. Standard `dotnet publish` omits these application-owned unpackaged WinUI payloads in this project; missing them produces a runtime `XamlParseException` before a window can be created.

## Verification requirements

- Release and self-contained startup must create a real HWND, render, and focus the query field;
- validate single instance, hotkey, focus, keyboard behavior, 500 lifecycle transitions, settings recovery, System/Light/Dark themes, tray actions, resources, and DPI on an interactive desktop;
- retain raw outputs under `artifacts\m10` and durable summary evidence under `docs\milestones\evidence\M10`.
