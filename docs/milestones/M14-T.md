# M14-T — Installer simplification and fixed-location contract

## Goal

Replace the M14-I arbitrary-directory compatibility policy with one narrow,
per-machine installation contract:

```text
Quail -> {autopf}\Quail
```

The installer must reject every other effective destination before prerequisite
execution or any Quail mutation.

## Scope

- Fix the application directory to `{autopf}\Quail`.
- Disable directory selection and previous-directory reuse, while independently
  validating both `WizardDirValue` and effective `{app}` at runtime.
- Reject `/DIR=`, `/LOADINF`, silent, interactive, and remembered-location
  destination overrides before bootstrap, payload copy, PATH, shortcuts, or
  uninstall registration.
- Remove the 0.1 187-file cleanup include and arbitrary custom-directory
  ownership recognition.
- Permit only a same-version AppId registration at the canonical location to
  reinstall a non-empty canonical directory.
- Require a manual uninstall before a different-version or custom-location
  registered Quail development build can be replaced.
- Retain the canonical machine-PATH entry and file-level Inno uninstall
  behavior; do not add an updater, migration framework, ACL evaluator, or
  recursive directory cleanup.

## Out of scope

- Application, package, runtime, feature, or data-schema changes.
- Cross-version automatic upgrade, rollback, migration, or obsolete-file
  cleanup.
- General ACL parsing or custom ACL management.
- Public-release work, tags, releases, visibility changes, or private-history
  changes.

## Verification

Run Release tests and App/CLI builds, Windows App Runtime detection, the
installer fixed-location guard, M14-P release provenance guard, canonical
installer/prerequisite/payload guards, privacy scan, `git diff --check`, and
the focused Quail-Lab T1–T10 installer/security matrix.

## Stop condition

Record `remediation blocked` if a noncanonical destination remains selectable,
the fixed-location policy needs material redesign or custom ACL management,
application source/packages must change, or the required lab security result
cannot be established without an unauthorized environment change.
