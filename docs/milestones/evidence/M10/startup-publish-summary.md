# Startup and publish summary

The self-contained M10 publish is generated by `scripts/publish-m10.ps1`. Its guard requires `App.xbf`, `QuickSearchWindow.xbf`, `Quail.pri`, the approved UI SVG, approved 32 px and 48 px application PNGs, and the approved 16 px tray PNG.

The initial standard publish omitted the XBF/PRI payload and caused `Application.LoadComponent` to throw `XamlParseException`. The guarded publish fixes that failure mode.

The previous direct self-contained measurement reached `visible-ready` in 452.287 ms after a 635.724 ms warmup. It reported a 700×370 HWND at 96 DPI with the query box focused. The final QA-round publish also completed an exit-after-`visible-ready` run with exit code 0. A direct second launch requested activation from the primary single instance and then exited with code 0.

After the final search-box-polish build, self-contained publish completed with 526 files and 237587954 bytes. `Quail.exe` reached `visible-ready` and exited with code 0. Controlled startup logged `WS_EX_TOOLWINDOW`, no `WS_EX_APPWINDOW`, `WS_DLGFRAME` removal with `SWP_FRAMECHANGED`, and successful `DWMWA_BORDER_COLOR = DWMWA_COLOR_NONE`. It also logged `NOTIFYICONDATAW NIM_SETVERSION size=976 versionOffset=816 version=4`, proving the managed W-layout supplied to `Shell_NotifyIconW`. PE-resource verification found the approved 16 px small-icon plus unchanged 32 px, 48 px, 64 px, 128 px, and 256 px PNG frames embedded in the published executable.
