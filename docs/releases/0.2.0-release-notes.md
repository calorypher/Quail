## What is included

Quail 0.2 is a Windows-first, local-first file search application. It provides
a WinUI desktop shell with Quick Search, a global hotkey, tray integration,
persistent GUI-managed local NTFS indexes, and the `Quail.Cli` command-line
tool.

## Requirements and installation

- Windows 11 x64 on an NTFS volume.
- Run `Quail-0.2.0-Setup.exe` with normal Windows elevation.
- Installation is fixed at `C:\Program Files\Quail`; a custom destination is
  not supported.
- The installer detects, then downloads and hash-verifies only missing .NET 10
  Desktop Runtime, Windows App Runtime, and x64 Visual C++ Redistributable
  prerequisites from Microsoft.
- A new terminal can run `Quail.Cli --help` because the canonical Program Files
  directory is added to the system `PATH`.

SHA-256: **To be finalized in M14-B from the post-rename release artifact.**

## Known limitations

Quail 0.2 searches indexed local NTFS file and directory names. It does not
provide content indexing, cloud or network indexing, third-party plugins, a
Windows Service, automatic updates, or a cross-platform build. Building or
synchronizing a full-volume index can require an elevated CLI process.

## Development-release status

This is Quail's first public development release, not a stability or feature
promise for later roadmap work. The installer and binaries are unsigned.
Windows SmartScreen or reputation warnings may appear. Verify the published
SHA-256 before running the installer; code signing can be revisited for a later
release.

Uninstall through Windows Installed apps or Quail's generated uninstaller. It
removes Quail and its own system `PATH` entry but does not remove user index
data.
